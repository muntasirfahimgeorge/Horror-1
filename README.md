# 🎬 Horror-1

A horror-themed web project built with HTML, CSS, and JavaScript, featuring animated visual effects, horror-themed images, and background audio.

## 🌐 Live Demo

[View Live Project](https://muntasirfahimgeorge.github.io/Horror-1/)

## 📖 Overview

Horror-1 is a front-end web project created to explore horror-themed web design, animations, visual effects, and multimedia elements.

The project combines a dark visual style with images, CSS styling, JavaScript animation, and audio to create an immersive horror-themed experience.

## ✨ Features

- 🎨 Horror-themed visual design
- 🖼️ Multiple horror-themed images
- ✨ JavaScript animation effects
- 🎵 Background audio
- 📱 Front-end web interface
- 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
